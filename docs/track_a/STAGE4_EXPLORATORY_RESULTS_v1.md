## 1. Design

A factorial over the replication-fidelity axes in `REPLICATION_FIDELITY_v1.md`, so each deviation from Hu et al. is *measured* rather than assumed:

| Axis | Settings | Decision |
| --- | --- | --- |
| Feature set | base (29 dims), temperature (57 dims) | D-012 |
| Context condition | nearest, sampled | D-013 |
| Seed | 20260729, 20260730, 20260731 | freeze §8 |
| Held-out event | E08_20110202, E14_20210212, E21_20260125 | D-011 |
| Arm | CNP, AdaCNP | freeze §1 |

Both arms in a cell share that cell's normalizer and its persisted context-index file, so **only the within-cell paired difference is comparable**. Per-fold normalization makes NLL values incomparable across events, which is why no cross-event average of raw NLL appears anywhere below.

Training length is not fixed by hand: each run trains to a ceiling and the reported parameters are those with the best **inner-validation** NLL, drawn from the fold's own training partition (D-014). Selecting on the held-out event would be leakage.

## 2.1 Effect decomposition

Cell means alone conflate the two axes. This table isolates each, per event, averaged over the other axis and all seeds. It is the most informative view here: a small effect that is **consistent in sign across events** is better evidence than a large one that flips.

| Event | Adding temperature | Sampled vs nearest |
| --- | ---: | ---: |
| E08_20110202 | +0.758 | +0.476 |
| E14_20210212 | +0.766 | +0.146 |
| E21_20260125 | +0.436 | -0.158 |
| **mean** | **+0.653** | **+0.155** |

Both columns are the change in the paired CNP − AdaCNP difference, so positive means the change **helped AdaCNP relative to CNP**.

**Temperature is the dominant axis.** It is positive for every event and several times the size of the context effect. The context effect is inconsistent in sign across events, and once temperature is present the two conditions are nearly indistinguishable. An earlier single-event probe suggested the reverse; the full grid does not support it, and that earlier reading is superseded.

The interpretation this supports: **AdaCNP's mechanism cannot be tested on temperature-defined events in a feature space with no temperature.** Its adaptive layer scores similarity between context and target embeddings; with calendar and load lags alone there is no cold-analogue signal for it to find.

## 6. Structural protections

Asserted by test, not by inspection:

- **Leave-one-event-out**, one fold per load-eligible event, count derived from the imported inventory (D-006, freeze §10.1).
- **±7-day buffer excluded from training and retrieval** (freeze §3), including through the lag features. This is the defect fixed on 2026-07-29: the lag span was computed from the target day's first hour rather than the issuance cutoff, understating its reach by ~15 hours. See `CURRENT_STATE.md`.
- **No context day is drawn from inside the held-out buffered window.**
- **Both arms consume one persisted context-index file per episode set**, re-read from disk by each arm.
- **Normalization**: fold training partition only.
- **Stopping**: inner validation drawn from the fold training partition; never on the held-out event.
- **Issuance safety**: 09:00 `America/Chicago` on D−1 through the timezone database, no fixed UTC offset anywhere (D-007).

## 7. Limitations recorded, not resolved

1. **Censored values enter the inputs.** A held-out day's lag features are observed served load, which for later event days may include `verified_shed` hours. D-010 removes those hours from the *metric*, not from the *inputs*.
2. **`unresolved` contamination.** Most scored hours are `unresolved`. If any were in fact shed, the primary metric is contaminated by an unknown amount. D-010 accepts this knowingly; the record cannot resolve it.
3. **Inner validation is a weak proxy for the extreme regime.** Inner-validation NLL varies far less than held-out extreme NLL, because extreme events are out-of-distribution relative to the normal periods it is drawn from. This is the distribution-shift problem the paper exists to address, visible in Track A's own data. No leakage-free alternative selects on the extreme regime.
4. **No forecast temperature.** The temperature features are past-observed only; the corpus holds no day-ahead forecast product with historical issuance timestamps. Hu et al. additionally use next-day forecast temperature for PJM.
5. **Two events lose held-out days to temperature gaps** in the `temperature` set (E05 3→1, E07 4→3). Neither is in this trio, but any stage-5 result must state it.
6. **n is small.** Three events per cell. Paired differences across seeds give a spread, not a hypothesis test, and the freeze specifies no inferential procedure.
